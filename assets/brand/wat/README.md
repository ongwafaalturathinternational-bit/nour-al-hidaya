# Ressources officielles — WAT Connect

Déposer ici les quatre PNG originaux de l'archive WAT, sans retouche ni conversion :

| Nom à conserver | Usage |
|---|---|
| `WC copie.png` | Logo complet couleur |
| `WC blanc.png` | Logo complet blanc |
| `ICONE WC.png` | Icône couleur |
| `ICONE WC blanc.png` | Icône blanche |

Les fichiers doivent être déposés dans ce dossier `assets/brand/wat/`. Les noms peuvent être conservés exactement comme dans l'archive. Ne pas ajouter de version recréée, vectorisée ou compressée avec perte.
