# Ressources officielles — Nour Al-Hidaya

Déposer ici les quatre PNG originaux de l'archive Nour, sans retouche ni conversion :

| Nom à conserver | Usage |
|---|---|
| `logo nour alhidaya.png` | Logo complet couleur |
| `logo blanc nour alhidaya copie.png` | Logo complet blanc |
| `ICONE NOUR ALHIDAYA.png` | Icône couleur |
| `ICONE blanc NOUR ALHIDAYA copie.png` | Icône blanche |

Les fichiers doivent être déposés dans ce dossier `assets/brand/nour/`. Les noms peuvent être conservés exactement comme dans l'archive. Ne pas ajouter de version recréée, vectorisée ou compressée avec perte.
